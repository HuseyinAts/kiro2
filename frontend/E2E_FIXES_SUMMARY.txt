SELECTOR IMPROVEMENTS
--------------------
Before:

After:
  const button = page.getByRole('button', { name: /İnceleme için işaretle/i })
    .or(page.locator('button:has(svg[data-testid="FlagIcon"])'));

Strategy:
  1. data-testid (most reliable)
  2. Role + name (semantic)
  3. Text with regex (flexible)
  4. CSS/element (last resort)
