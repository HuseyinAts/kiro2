## 3. Auth model

Dual-channel — `core/dependencies.py:dual_auth`:

1. **Cookie (frontend, default)**: httpOnly access (15min) + refresh
   (7d), `samesite=lax`, `secure=not _IS_DEV`.
2. **Bearer (API clients)**: JWT in `Authorization: Bearer ...`.

Both end at `AuthenticatedUser` (Pydantic). Some legacy code uses
`Kullanici` (Turkish ORM model with different fields) — Session 179
identified 172 call sites mistyped as `current_user: User`; see
audit task B-P0-21 type-design sweep.

2FA: TOTP-based, optional. Frontend now propagates
`requires_2fa: true` signal — UI flow consumer still pending (B-P0-24).

## 4. Algorithm pipeline (per quiz answer)

Order of operations in `services/bkt_service.record_answer()`:

```
1. BKT update  → p_learn(topic_id)
2. IRT theta   → theta(subject_id) via EAP estimator
3. FSRS card   → next_review_date(student, topic)
4. ZPD zone    → MASTERED / ZPD_ACTIVE / FRUSTRATION
```

The pipeline is synchronous by default (consistent state). Set
`ALGO_FIRE_AND_FORGET=true` for load-tested deploys to detach the
pipeline into `asyncio.create_task(...)` (S179 fix B-P0-23).

Critical case-convention rule (`.claude/rules/case-convention.md`):
- DB columns store `subject_area` UPPERCASE (`"MATEMATIK"`)
- BKT slugs are lowercase (`"matematik"`)
- FSRSCard.subject_area uses SubjectArea enum (lowercase value)
- `dag_service.get_subject_topics()` expects UPPERCASE (defensive)

## 5. Middleware ring (request → response)

```
client
  → CORSMiddleware
  → VersionRedirectMiddleware (legacy /api/X → /api/v1/X)
  → AuthRateLimitMiddleware
  → CSRFProtectionMiddleware
  → AuthMiddleware (resolves AuthenticatedUser)
  → TimingMiddleware
  → CacheMiddleware
  → request_size_limit + ddos_protection (return JSONResponse, never raise)
  → FastAPI routing
```

`.claude/rules/middleware.md`: middleware MUST `return Response`, not
`raise HTTPException` — raises become plain 500 to the client.

## 6. Beta-launch architecture decisions

- **Single backend container**, 1 uvicorn worker (`Dockerfile.minimal`).
  Production multi-worker `Dockerfile` exists but is not the deploy
  default until PgBouncer lands.
- **Connection pool:** `db_pool_size=15`, `max_overflow=30` per
  `.env.mvp`. PG `max_connections=100`, so 4 backend workers fit.
- **No CDN** for `/static/crops` (87K question images). Beta load
  tolerable; 1K+ student scale needs Cloudflare R2 + signed URLs.
- **Login rate limit:** 30/60s/IP (env override
  `LOGIN_RATE_LIMIT_PER_MINUTE`). Pre-fix 10/60s blocked shared-NAT
  classrooms.
- **CORS:** `ALLOWED_ORIGINS` env var, refuses to start in production
  if unset.
- **Redis:** maxmemory 512MB, LRU eviction. Cache-only — no critical
  state.

## 7. Path naming

`.claude/rules/path-naming.md` is the rule. New endpoints MUST be
under `/api/v1/<english>`. Legacy `/api/v1/ogretmen/*` and
`/api/v1/veli/*` redirect via `VersionRedirectMiddleware`. Brand-name
exceptions: `bilge-alp`, `soru-meydani`, `oba-seferleri`,
`usta-cirak`, `cozum-duellosu`, `zpd-maarif`, `kvkk`.
